# ESP8266 智能环境监测系统

基于 ESP8266 的环境监测与控制系统，支持温湿度、光照实时监测，风扇/加湿器远程控制，蜂鸣器阈值报警及静音管理，接入巴法云支持小爱同学语音控制。

## 功能特性

- **温湿度监测**: DHT11 传感器实时采集，TFT 屏幕显示
- **光照监测**: 光敏电阻 GL5506 模拟量换算 lux，同时显示百分比
- **自动息屏**: 光线低时屏幕自动熄灭，省电护眼
- **设备控制**: 风扇、加湿器各一路三极管放大电路驱动，支持本地/网页/语音控制
- **蜂鸣器报警**: 温度/湿度超阈值或屏幕熄灭时响 1 秒，迟滞防反复触发
- **蜂鸣器控制**: 支持网页与小爱同学统一控制，`on` 为开启蜂鸣器，`off` 为关闭/静音
- **巴法云接入**: MQTT 协议，数据上报 + 指令下发
- **Web 控制台**: H5 手机端 + PC 端网页，实时数据与设备控制
- **NTP 时间同步**: 屏幕和网页同步显示年月日时分秒星期
- **启动动画**: 旋转 Logo + WiFi 连接动画

## 硬件配置

| 组件 | 引脚 | 说明 |
|------|------|------|
| DHT11 | D6 (GPIO12) | 温湿度传感器 |
| 光敏 AO | A0 | 光照模拟量读取 |
| 光敏 DO | D8 (GPIO15) | 光照数字量（控制息屏） |
| 风扇 | D2 (GPIO4) | 三极管放大驱动 |
| 加湿器 | D1 (GPIO5) | 三极管放大驱动 |
| 蜂鸣器 | D0 (GPIO16) | 低电平触发 |
| TFT 屏幕 | SPI | TFT_eSPI 驱动（D3/D4/D5/D7） |

## 巴法云配置

1. 注册 [巴法云](https://bemfa.com) 账号
2. 获取私钥(UID)
3. 创建五个主题：
   - `temp004` - 温湿度上报（小爱查询）
   - `data004` - 光照 + 设备状态上报
   - `fan003` - 风扇控制
   - `light003` - 加湿器控制
   - `mute004` - 静音控制

修改 `src/main.cpp` 中的配置：

```cpp
const char* BEMFA_KEY = "你的私钥";
```

## 数据格式

- **temp004**：`#温度#湿度`（标准格式，供小爱查询）
- **data004**：`#光照百分比#lux#风扇状态#加湿器状态`

示例：`temp004 → #27#81`、`data004 → #65#230#off#on`

## 网页端使用

- **H5 手机端**: 直接浏览器打开 `h5.html`
- **PC 端**: 直接浏览器打开 `pc.html`

网页通过 WebSocket 连接巴法云 (`wss://bemfa.com:9504/wss`)，实时接收数据并支持设备控制。

## 报警阈值

代码中默认阈值（可后续改成可调）：

```cpp
float TEMP_ALARM = 29.0;   // 温度报警阈值（℃）
float HUMI_ALARM = 96.0;   // 湿度报警阈值（%）
const int BEEP_MS  = 1000; // 蜂鸣时长（ms）
```

迟滞设计：温度需降到 28℃ 以下、湿度需降到 94% 以下才能再次触发，避免在阈值附近抖动反复响。

## 开发环境

- **IDE**: VSCode + PlatformIO
- **开发板**: ESP8266 (NodeMCU v2)
- **框架**: Arduino

## 分支说明

- `main`: 基础功能
- `feature/bemfa-cloud`: 巴法云接入 + 双设备控制
- `feature/light-sensor`: 光敏传感器 + 自动息屏
- `feature/buzzer-alarm`: 蜂鸣器报警 + 静音控制
