# ESP8266 智能温控系统

基于 ESP8266 的环境监测与智能控制系统，支持温湿度实时监测、双风扇远程控制、巴法云 IoT 平台接入及小爱同学语音控制。

## 功能特性

- **温湿度监测**: DHT11 传感器实时采集，TFT 屏幕显示
- **双风扇控制**: 支持本地/远程/语音三种控制方式
- **巴法云接入**: MQTT 协议连接，数据上报与指令下发
- **Web 控制台**: H5 手机端 + PC 端网页，实时数据显示与风扇控制
- **NTP 时间同步**: 自动校时，屏幕和网页同步显示
- **启动动画**: 旋转 Logo 和 WiFi 连接动画效果

## 硬件配置

| 组件 | 引脚 | 说明 |
|------|------|------|
| DHT11 | D6 (GPIO12) | 温湿度传感器 |
| 风扇1 | D2 (GPIO4) | 继电器控制 |
| 风扇2 | D1 (GPIO5) | 继电器控制 |
| TFT 屏幕 | SPI | TFT_eSPI 库驱动 |

## 巴法云配置

1. 注册 [巴法云](https://bemfa.com) 账号
2. 获取私钥(UID)
3. 创建三个主题：
   - `temp004` - 温湿度数据上报
   - `fan003` - 风扇1 控制
   - `light003` - 风扇2 控制

修改 `src/main.cpp` 中的配置：

```cpp
const char* BEMFA_KEY = "你的私钥";
```

## 数据格式

温湿度上报格式：`#温度#湿度#风扇1状态#风扇2状态`

示例：`#28#65#off#on`

## 网页端使用

- **H5 手机端**: 直接浏览器打开 `h5.html`
- **PC 端**: 直接浏览器打开 `pc.html`

网页通过 WebSocket 连接巴法云 (`wss://bemfa.com:9504/wss`)，实时接收数据并支持风扇控制。

## 开发环境

- **IDE**: VSCode + PlatformIO
- **开发板**: ESP8266 (NodeMCU)
